# Brain Tumour MRI Classification Using Deep Learning

## Project Overview

This project develops an AI-based deep learning system for classifying brain MRI images into four categories:

- Glioma
- Meningioma
- Pituitary Tumour
- No Tumour

The project compares different deep learning approaches for medical image classification.

## Models Implemented

- Artificial Neural Network (ANN)
- Baseline CNN
- Improved CNN
- ResNet50 Transfer Learning
- MobileNetV2 Transfer Learning
- EfficientNetB0 Transfer Learning

## Evaluation Metrics

The models were evaluated using:

- Accuracy
- Precision
- Recall
- F1-score
- Confusion Matrix

## Dataset

Brain Tumour MRI Dataset (Kaggle)

The dataset is not uploaded because of size limitations. The notebook contains the complete implementation.

## Best Model

EfficientNetB0 achieved the highest classification performance among the tested models.
